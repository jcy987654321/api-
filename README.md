# API Viewer

强大的管理系统

## Getting Started

```bash
npm install
npm start
```

This launches the API viewer on [http://localhost:3000](http://localhost:3000). The home page lists all whitelisted APIs in the catalog. Selecting an API opens a detailed view with metadata, usage instructions, and an integrated online tester.

## Testing

```bash
npm test
```

Unit tests cover the proxy service (using mocked HTTP responses) and the parameter rendering utilities.
